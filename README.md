## 🌟 주요 사업 및 솔루션 영역

1. **Remote AI (로컬 AI 에이전트 원격 통제소)**
   - PC 로컬 환경의 다양한 AI 워커(Codex, Antigravity, Claude 등)를 모바일 및 웹 대시보드에서 실시간 모니터링
   - 중요 명령/파일 수정 시 스마트폰에서 원터치 승인(Approval Gate) 및 안전한 토큰 페어링 지원
   - 📱 [Android Supervisor APK 다운로드 (GitHub Release)](https://github.com/han1991bit/remote-codex/releases)
   - 💻 [Remote Codex GitHub 저장소](https://github.com/han1991bit/remote-codex)

2. **엔터프라이즈 업무 자동화 파이프라인 (Enterprise AI Workflow)**
   - 사내 반복 업무 및 복합 비즈니스 프로세스 무중단 자동화 시스템 구축

3. **맞춤형 LLM & 도메인 특화 AI (Custom LLM & RAG)**
   - 보안이 보장된 사내 지식 기반 RAG 및 기업 도메인 맞춤형 LLM 파인튜닝

4. **데이터 지능화 & 고급 예측 분석 (Data Intelligence & Analytics)**
   - 대규모 시계열 및 정형/비정형 데이터 분석, 알고리즘 기반 비즈니스 인사이트 도출

5. **멀티모달 & 시각 지능 솔루션 (Multimodal & Vision Solutions)**
   - 문서 OCR, 도면 분석 및 시각 지능 기반 인터랙티브 시스템

6. **AI 도입 전략 컨설팅 & 보안 인프라 (AI Strategy & Security)**
   - 기업별 AI 도입 타당성 검토 및 온프레미스/클라우드 하이브리드 인프라 아키텍처 설계

## 🛠️ 기술 스택 (Tech Stack)

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **CI/CD**: GitHub Actions (GitHub Pages 자동 배포)
- **Domain**: [milkywayai.co.kr](https://milkywayai.co.kr)

## 🚀 로컬 개발 및 실행 (Getting Started)

### 사전 요구사항
- Node.js (v18 이상 권장)

### 패키지 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm run dev
```

### 프로덕션 빌드
```bash
npm run build
```
